木村 优介

Yusuke Kimura

自然语言处理 / 大语言模型后训练 / 跨分词器知识蒸馏

我研究大语言模型的后训练，旨在使模型能够针对不同任务与应用环境进行高效、可靠的适配。我尤其关注词表和分词器不同的模型之间如何迁移知识，以便将现有模型的能力灵活地传递给其他模型。此前，我还开展过多任务学习、文本分类和关键短语抽取研究；在合作研究中，也参与了有限计算资源下的适配器学习与社会偏见缓解。

研究方向

主攻方向

词表与分词器不同的 LLM 之间的知识蒸馏

针对教师模型与学生模型因词表和词元切分方式不同而难以直接比较输出的问题，我研究将双方输出对齐到统一表示形式的后训练方法，使不共享同一分词器的 LLM 之间也能迁移知识。

合作研究

有限计算资源下的高效适配器学习

通过量化调度器与依据训练进度调整的分层动态量化，在有限计算资源下适配大语言模型（基于获批 HPC 课题的合作研究）。

合作研究

高可靠性适配：偏见缓解与知识接地生成

通过激活引导（activation steering）缓解社会偏见，并优先依据外部知识生成输出，实现更可信的大语言模型适配（合作研究）。
